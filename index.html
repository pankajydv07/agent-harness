Context Limit Enforcement

12 Turns.
Then The Subagent
Dies.

Most agent frameworks allow loops to spiral into hallucinations and endless token burn. MyAgent enforces crisp turn boundaries: subagents spin up in completely clean, isolated context windows, perform their targeted research or coding task, and terminate. Only structured findings cross back.

02

How It Runs

01
Prompt
User enters prompt into the Rich terminal UI. Task parameters, tool schemas, and environment rules load deterministically.
02
Isolate
Root agent dispatches ephemeral subagent with a dedicated context window. Zero contamination of master conversation history.
03
Execute
Sandboxed bash commands and file operations run with a strict 60s timeout guard and approval policies.
04
Verify
Pytest suite validates code modifications. Findings serialize into structured handoffs; memory compacts at 80%.

The 7 Native Tools

Tool Signature Description Containment
bash command: str Executes shell commands in a sandboxed subprocess. Captures stdout/stderr with output trimming. 60s Timeout
read_file path: str Reads file contents with automatic context read-tracking to prevent redundant retrieval. Read-Tracked
write_file path: str, content: str Creates new files or overwrites existing files deterministically. Deterministic
str_replace path: str, old_str, new_str Surgical in-place text replacement. Guarantees safety by rejecting non-unique substrings unless multi-edit is explicitly flagged. Collision Safe
task description: str Dispatches an ephemeral subagent with its own fresh context window to handle isolated sub-tasks. Max 12 Turns
write_todos todos: list[dict] Structured task progress tracking conforming to strict schema enforcement. Schema Enforced
read_skill name: str Loads on-demand specialized domain instructions and workflow cheatsheets. Modular

Quickstart

TERMINAL // INSTALL & RUN 
# 1. Clone repository
git clone https://github.com/pankajydv07/agent-harness.git
cd agent-harness/my-agent

# 2. Setup virtual environment
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate

# 3. Install in editable mode
pip install -e .

# 4. Configure environment
cp .env.example .env

# 5. Launch MyAgent
myagent

Architectural Highlights

  • Zero Bloat: Pure Python implementation without thousands of unnecessary abstraction layers.
  • Rich Terminal UI: Live streaming markdown output, status spinners, and error alerts.
  • Subagent Quarantine: Independent turn budget ensures subagents cannot hijack root execution.
  • Automatic Compaction: Conversation history compacts at 80% token capacity via structured summaries.
  • OpenAI Compatible: Drop-in support for any OpenAI-compatible LLM endpoint.
